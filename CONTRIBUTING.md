# Contributing

Thanks for your interest in improving this project.

## Development setup

1. Install dependencies:
   - `npm install`
2. Start the dev server:
   - `npm run dev`
3. Run lint before opening a PR:
   - `npm run lint`
4. Build to validate production output:
   - `npm run build`

## Branch naming

Use descriptive branch names:

- `feat/<short-description>`
- `fix/<short-description>`
- `docs/<short-description>`
- `chore/<short-description>`

## Commit style

Use Conventional Commits:

- `feat: add project filter section`
- `fix: prevent crash in playground route`
- `docs: update setup instructions`

## Pull requests

- Keep PRs focused on one topic.
- Add screenshots for visual changes.
- Update docs when behavior changes.
- Link the related issue when possible.
